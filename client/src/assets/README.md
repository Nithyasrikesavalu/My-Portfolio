# Assets

Drop your real files here. They are picked up by base name (jpg, jpeg, png, webp, svg; pdf for the resume), so no code changes are needed:

| Put this file                                              | Used for                                  |
| ---------------------------------------------------------- | ----------------------------------------- |
| `profile.jpg`                                              | Hero and About portrait                   |
| `projects/botvortex.png`                                   | BotVortex preview                         |
| `projects/one_tap.png`                                     | OneTap Service preview                    |
| `projects/coffee_shop.png`                                 | Giggling Platypus preview                 |
| `projects/employee_tasks.png`                              | Employee Task Management System preview   |
| `projects/hostel_review.png`                               | Hostel Review Application preview         |
| `projects/Nithyasri_resume.pdf` (or .jpg/.png)             | "Download Resume" button                  |

Until a file exists, a clearly labelled placeholder is shown. Project text and links live in `src/data/projects.js`; personal links live in `src/data/site.js`.
